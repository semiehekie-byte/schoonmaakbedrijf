## Evaluatie

Het is gelukt om een eenvoudige website voor een fictief schoonmaakbedrijf te maken met HTML, CSS en JavaScript.

Het product is binnen de geplande tijd gemaakt.

Mijn leerdoelen zijn grotendeels gelukt. JavaScript en Css vind ik nog moeilijk omdat ik daar weinig ervaring mee heb.

HTML vond ik makkelijk. CSS was iets moeilijker en JavaScript het moeilijkst.

Voor een volgend project wil ik meer met ai gaan werken, omdat ai de site er profesioneler uit kan laten zien, zonder dat het meer tijd kost om een site te maken.

Ik heb geleerd dat HTML en CSS het belangrijkste is voor een website, en dat javascript niet altijd nodig is.

Ik verwerk geen persoonsgegevens en gebruik alleen stockfoto's.

Ik ben tevreden over mijn werkwijze en eindproduct.
